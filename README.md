# Maison Muse – model booking website
Host free on GitHub Pages: Settings → Pages → Deploy from branch → main / root. Pages: index, models, categories, about, contact, profile.

Edit only `data.js`:
- SITE: every heading, quote and button text
- CATEGORIES / LOCATIONS: the 3 categories and the area list
- MODELS: name, image, rate, phone (91XXXXXXXXXX), services, about, featured: true/false
Put photos in the `images` folder (e.g. images/aanya.jpg) and match the file name in `image`.
Edit rates in RATES (data.js). Every text, model and image is in data.js.
